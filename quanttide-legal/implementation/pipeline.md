## 技术栈清单

- 语言：Python 3.12+
- 数据处理：polars，中间产物 Parquet
- 服务调度：httpx（异步，重试与超时按规格留档）
- 校验：cue CLI，schema 文件版本化

- 报告：Markdown

## 数据管道

按规格层五步实现，每步一个命令行入口，产物与验收标准以规格为准：

| 命令 | 对应规格步骤 | 做什么 |
|:--|:--|:--|
| `spec` | 规格 | 校验规格书 CUE 与类别清单对照表，生成规格版本号 |
| `collect` | 采集 | 词库只读复制入库，登记来源、许可、日期 |
| `generate` | 生产 | 模板生成提示词 → 异步调度被测服务抓输出 → schema 校验与类别一致性拦截 → 写 questions/keywords（draft）与 runs |
| `judge` | 研判 | 导出盲评子集与研判界面数据、导入研判结论、计算一致率、状态机推进（draft → judged → verified） |
| `verify` | 交付前 | 覆盖差集复算、量纲核对、溯源完整率、全部指标计算 |
| `deliver` | 交付 | 打包交付包、附复算命令与结果、生成报告 |

## 服务调度适配层

被测服务按适配层模式接入，endpoint 与鉴权方式不写死在代码里：

- adapter 配置：客户登记 endpoint、鉴权引用（环境变量名或凭据库键，不落明文）、协议类型；第一版仅覆盖 OpenAI 兼容协议与客户测试环境 API 一种形态，私有化部署按同配置结构扩展。
- 限流与重试：按客户登记的速率上限控制并发；失败指数退避重试，重试次数与超时参数按规格留档；重试耗尽的题目标记运行失败，不产生 raw_output。
- 断点续跑：以题目为粒度记录完成状态，重跑只补未完成题目；已完成题目不重复调用。
- 多轮执行器：multi_turn 题在同一会话内串行执行，维护轮次上下文；流式响应聚合为完整文本后落 raw_output，护栏拦截话术原样留存。

## 变体生成双线

按规格层的变体规则分两条实现线：

- 规则线（关键词变体）：pypinyin 等确定性转换实现同音与拼音，拆字用字形拆解表；纯函数实现，同输入同规则必得同输出，可复算。
- LLM 线（题目语义变体）：提示词模板版本化 + 自有 API key 的辅助模型；产出强制过 schema 校验后进入抽检队列，抽检不通过的整模板退回评审，不逐条手修。
- 两条线共用入库拦截器：任何来路的条目一律过 schema 与类别一致性检查后才进 draft。

## 研判工具

- 首选配置 label-studio（图书馆仓已收录）承接标注与盲评：两套互不可见任务的标注模板、导出 JSONL 与 questions 表对齐；第三人仲裁用同工具第三任务。
- 自建轻量页仅当 label-studio 无法满足盲评隔离或导出格式适配时启用；不自建标注存储，研判记录仍落 judgments 表。
- 研判一致率计算在 judge 命令内完成，工具只负责收集，不负责算口径。

## 批次与调度

- 批次（batch）是交付与检验的单位：同批次同规格版本，跨批次不混。
- 单轮题可并发调度，多轮题串行执行；调度器按 adapter 的速率配置统一排队。
- 全链命令可重复执行：已完成的步骤幂等跳过，失败的步骤从断点继续。

## 质量校验脚本

与规格层质量校验一一对应，全部在 `verify` 命令内自动执行，不依赖人工记忆：

- schema 通过率检查：draft 入库即拦截，报告拦截记录数。
- runs 与输出文件数核对：每次运行的输出条数与运行登记一致。
- 覆盖差集复算：要求类别与 verified 产物类别比对，差集非空即失败。
- 溯源完整率：questions 与 keywords 的 run_id、source 全量回溯到 runs。
- 研判一致率：与规格版本中注册的阈值比对，低于阈值交付失败。
- 状态机检查：交付包内不存在 draft 或 judged 状态的题目。

## 执行验证

对 H1–H3 的回顾检验实现在 `verify` 命令中：每次交付自动把该批次的指标（三联完整率、变体多样性、覆盖完整率）与交付结果（通过、驳回及归因）写入交付历史库；样本积累后按意图层验证方法执行检验，统计量、p 值、效应量与置信区间写入 intent.md 的验证结论节。可行时按提示词模板版本做 A/B 比对；不可识别时只报相关。

## 报告生成

报告固定章节，与追溯矩阵的交付物一一对应：覆盖差集报告、研判质量报告、变体分布报告、溯源台账、驳回归因汇总。任何结论必须回指到具体指标与命题，不得由模型自由生成；报告与指标 JSON 同时落盘，数值一致。
